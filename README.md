# Games Shop Website

This project is a modern gaming shop website that allows users to browse games, explore product details, and simulate purchasing games through a responsive and interactive interface.

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Bootstrap 5
* jQuery

## Deployment

The website was deployed using:

* GitHub Pages
* Firebase Hosting

## Features

* Responsive gaming shop design
* Browse games and products
* Product detail pages
* Modern and interactive user interface
